## 一句话

DeepSeek 把中国大模型的叙事从“谁的参数更大”改成“谁的单位算力更值”：V2 用 MLA 和 MoE 把推理成本压下来，V3 用 671B 总参数、37B 激活参数和 14.8 万亿 token 证明大模型不必全程满负荷，R1 用纯强化学习让模型自己“刷题”出推理能力。它不是“零成本神话”，而是把训练和推理的效率账本摊开给人看。

## 时间·人物·机构

2023 年，梁文锋创立深度求索（DeepSeek）；据公开资料，他同时是幻方量化的创始人，团队把量化交易里对算力效率的敏感带进模型研发。2024 年 5 月，DeepSeek-V2 发布：2360 亿总参数、每 token 激活 210 亿，128K 上下文，8.1 万亿 token 预训练；相比 DeepSeek 67B，训练成本省 42.5%，KV cache 减少 93.3%，最大生成吞吐提升 5.76 倍。2024 年 12 月 27 日，V3 技术报告上线：6710 亿总参数、每 token 激活 370 亿，14.8 万亿 token 预训练，完整训练 278.8 万 H800 GPU 小时；按每小时 2 美元估算，总训练成本 557.6 万美元，报告明确说这只算正式训练，不含前期研究和消融实验。2025 年 1 月 20 日，R1 发布：官方称性能与 OpenAI o1 相当，模型和代码 MIT 许可，6 个蒸馏小模型开源，32B/70B 版本对标 o1-mini；API 定价为每百万输入 token 0.14 美元（缓存命中）/0.55 美元（未命中），输出 2.19 美元。R1 论文 2025 年发表于《自然》第 645 卷，页码 633–638。人物：梁文锋（深度求索）、Daya Guo（DeepSeek-AI，R1 论文第一作者）。

## 为什么是这个时候

第一，算力被卡。b31-c4 讲过，2022–2023 年的出口管制让最先进 GPU 不好买；当“堆卡”这条路变窄，架构和工程效率就成了唯一能自己控制的变量。第二，V2 已经把技术底座铺好。MLA 把 KV cache 压成潜向量，DeepSeekMoE 用稀疏激活把“总参数”和“每 token 计算量”拆开；V3 在这两块上继续加码，才敢用 2048 张 H800 训练。第三，开源和 API 市场成熟。2023 年第一波大模型把接口、计费和开发者习惯养成了，R1 一发布就能直接被调用、被蒸馏、被集成。第四，全球对“低成本”有需求。企业不想为每个任务付最前沿的价格，创业公司更想要能自己部署的权重。大白话：算力像房租，涨到买不起时，大家才开始认真研究“怎么住得更省”——不是不租了，而是把空间利用率做高。准确地说，效率叙事是算法、架构、框架和硬件的协同优化，不是零算力。

## 怎么工作

第一层是省内存。MLA（多头潜在注意力，Multi-head Latent Attention）把每层要缓存的 Key/Value 压成一个低维潜向量，推理时再展开；V2 报告说 KV cache 减少 93.3%，这是长上下文和高并发能跑起来的关键。第二层是省计算。DeepSeekMoE 把专家切得更细，还保留共享专家；每个 token 只路由到少数专家，所以总参数 671B，实际激活 37B。第三层是省通信。V3 用 DualPipe 把计算和通信重叠，用 FP8 训练，把 2048 张 H800 的集群利用率拉高；报告说每训练 1 万亿 token 只需 18 万 H800 GPU 小时，约 3.7 天。第四层是省标注。R1 的 R1-Zero 版本跳过“人写推理过程”，直接用规则奖励做强化学习：答案对给分、格式对给分，模型自己试出反思、验证和换策略；AIME 2024 的平均 pass@1 从 15.6% 涨到 77.9%。之后 R1 再用少量冷启动数据和第二轮强化学习把可读性和安全性补上，最后蒸馏给 Qwen/Llama 系的小模型。大白话：MoE 像一家大酒楼只开相关灶台——菜单有 671 道菜，但每桌只点 37 道，厨房不用全开；MLA 像把整本账本压成摘要，查账时再展开。准确地说，MoE 是稀疏激活，MLA 是低秩压缩，两者都在“用更少的显存和带宽做同样多的活”。

## 它改变了什么

第一，训练成本第一次被写成一张可核对的小票。V3 报告把预训练、上下文扩展、后训练分别列成 GPU 小时和美元，还注明假设的租金；这让“大模型很贵”从一句感叹变成可以拆解的账。第二，开源模型追平闭源的叙事成立。V3 报告说它在代码和数学上是最强开源基座，对话版在标准基准上与 GPT-4o、Claude-3.5-Sonnet 可比；R1 官方说与 o1 相当，且 MIT 许可允许蒸馏和商用。第三，API 价格被重新锚定。R1 的输入 0.14/0.55 美元、输出 2.19 美元每百万 token，给国内 API 市场设了一个低价参照，云厂商和创业公司被迫跟进或解释差异。第四，蒸馏成为产品策略。R1 直接开源 6 个蒸馏模型，32B/70B 对标 o1-mini，让买不起大集群的团队也能用上“会推理的小模型”。第五，它把“效率”变成国家叙事的一部分：在算力受限的条件下，算法和工程能力成了可以公开比较的竞争力。

## 今天的地位

V3 和 R1 的权重仍在，R1 论文上了《自然》，MLA/MoE/RL 这套组合已经被国内外大量模型借鉴；2026 年 DeepSeek 官网已经在推 V4.1 Flash，说明这家公司没有停在 V3/R1。判断“基础仍在用”更准确：MLA、稀疏 MoE、FP8 训练、规则奖励强化学习、蒸馏，这些方法仍是今天低成本模型的标配；被取代的是具体 checkpoint 和榜单位置。它没有消灭“算力焦虑”，只是把焦虑从“买不到卡”转成“怎么把卡用得更满”。今天最诚实的定位是：DeepSeek 是效率叙事的分水岭，不是算力自由的终点。

## 争议与局限

第一，557.6 万美元不是“公司总投入”。报告自己写明只算正式训练，不含前期研究、架构消融、数据清洗和人才成本；把这张表当成“做个大模型只要 500 万美元”，是误读。第二，低成本不等于低价格。API 定价可以补贴，推理的 GPU、带宽和运维仍要钱；价格战打到最后，比的是谁能在低价下活下来。第三，基准测试有选择性。R1 的强项是数学、代码和 STEM 这类可验证任务，开放域写作、长对话和中文常识未必同样领先；AIME 分数也不能直接换算成“通用智能”。第四，强化学习的奖励设计会带来行为偏差。规则奖励能让模型学会“先验算再作答”，也可能学会“凑格式、钻空子”；长链推理还会带来过度思考、语言混杂和延迟。第五，地缘政治。出口管制和数据安全规则会影响开源权重的跨境使用，模型越强，越容易被放进审查清单。大白话：菜单上写“人均 50”，没算酒水和包厢费；低成本叙事最容易被忽略的，是那张没列出来的成本表。准确地说，DeepSeek 的价值在于把效率边界往前推了一步，而不是证明大模型可以免费。
