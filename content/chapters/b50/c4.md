## 一句话
训练就是先猜一个答案、看错多少、再把参数往少错的方向挪一点；2010 年前后，随机梯度下降把「每次只看一小批」变成了大数据时代的默认引擎。

## 时间·人物·机构
Léon Bottou 当时在 NEC Labs America（普林斯顿）工作，2010 年在 COMPSTAT 会议上发表《Large-Scale Machine Learning with Stochastic Gradient Descent》，把 SGD 的收敛性质与大数据的计算预算放进同一个框架。与他长期合作的是 Yann LeCun（纽约大学），两人在 1990 年代就合作研究过在线学习与随机梯度。

SGD 本身并不新：Robbins 与 Monro 在 1951 年就研究过随机逼近；但在深度学习语境里，它刚被重新论证为「大数据的第一选择」。术语要分清：批量梯度下降每次用全部 n 个样本；SGD 每次用 1 个；小批量每次用 m 个，实践中常见 32 到 256。

## 为什么是这个时候
Bottou 在论文开头给的理由很直接：过去十年数据增长快于处理器速度，瓶颈从「样本够不够」变成「算不算得完」。当 n 很大时，批量梯度下降每走一步都要扫一遍全部样本，单步成本是 n 的量级；二阶方法还要算 Hessian 或它的近似，成本更高。

可如果时间预算固定，把同样的时间花在「更粗但更多步」的更新上，反而能处理更多样本、降低估计误差。Bottou 与 Bousquet 2008 年把总误差拆成三块：近似误差（模型族够不够大）、估计误差（样本够不够多）、优化误差（优化器停得早不早）。小数据问题上，第三块可以压到很小；大数据问题上，时间成了硬约束，故意不精确的优化反而划算。

硬件也在推这一边：多核 CPU 与 GPU 能同时处理很多样本，单样本更新却喂不饱这些核；于是「小批量」从数学折中变成工程默认。

## 怎么工作
给定样本与损失，训练的目标是让「全部样本的平均错误」尽量小。批量梯度下降每一轮都算一遍全样本的平均方向，方向准，但每一步都要遍历 n 个样本。SGD 把它换成一个样本：每次只抽一个，用它的梯度当真实梯度的近似；这个估计没有系统性偏差，但带噪声。噪声不是白来的：它让参数在最优解附近抖动，收敛速度受方差限制。经典条件是学习率之和发散、平方和收敛；满足时，参数会以一定速度靠近最优解。单步成本只有常数级，所以按总时间算，SGD 在大数据上赢。

小批量把「抽一个」改成「抽 m 个」：把这一批样本的梯度取平均，再走一步。m 越大，梯度方差越小，大致按 1/m 降，但单步成本按 m 涨；m 小则噪声大、更新多。工程上的经验值来自 Goodfellow 等人的教材：GPU 上常用 2 的幂，典型范围 32 到 256，大模型有时试 16。每个 epoch 前必须打乱数据：Goodfellow 举了医学检验的例子——同一病人的五个血样排在一起，按顺序取 batch 会让每个 batch 高度相关，梯度估计有偏；随机抽样才能保证相邻梯度估计近似独立。

打个比方，SGD 像用一小勺尝锅里的汤，尝一口就调味；批量梯度下降像把整锅汤端起来测比重。准确地说，前者用无偏但高方差的梯度估计换取低单步成本，后者用全样本的平均换来更稳的方向。小批量则是舀一勺固定的量，既比一口准，又不用整锅端；准确地说，它把方差压到约 1/m，同时利用矩阵运算的并行度。

再打个比方，训练像每天做一套小测，错了就改；分数不一定每天涨，但一个学期下来进步更快。准确地说，它把「每步都精确」换成「在固定计算预算下，用带噪声的近似梯度换更多次参数更新与更多数据覆盖」。

收敛还依赖学习率。Bottou 的论文提醒：学习率降得太慢，参数方差降得慢；降得太快，期望值迟迟到不了最优。实践里常见阶梯衰减、余弦衰减或平均化；论文特别指出，二阶 SGD 与平均 SGD 在训练集上只扫一遍就能达到渐近有效——这对「数据太大、只能过一遍」的场景是关键卖点。

## 它改变了什么
第一，它把「优化精度」变成预算项：时间受限时，故意停在粗解、把省下的时间用来多看样本，可能得到更低的期望风险。

第二，它给深度学习提供了默认引擎：2012 年 AlexNet 用 GPU 训练 6000 万参数的卷积网络，训练循环就是「取小批量、前向、反传、更新」；没有 SGD 的吞吐，这种规模的实验无法在几天内跑完。第三，它把「在线学习」接进了产业系统：点击日志、推荐流、风控数据源源不断，算法不必等全量数据落盘，抽一批就更新一次，模型可以跟着数据漂移。

第四，它催生了一整条优化器改进路线：动量、AdaGrad、RMSProp、Adam，都是在 SGD 的更新式上改「步长」或「方向记忆」。

## 今天的地位
今天 SGD 没有退休，只是不再唯一。几乎所有深度学习框架都保留 SGD 优化器，视觉模型的大批量训练仍常把 SGD 加动量当作强基线；Bottou 论文里的「单遍扫描」「学习率衰减」「平均化」都变成了标准词汇。

另一方面，大模型训练更常用自适应优化器（Adam 及其变体），因为不同参数的梯度尺度差异更大，逐参数调步长更省事。小批量则彻底制度化：batch size 是每个训练脚本的第一个超参数，梯度累积让显存不够时用多个微批量拼出等效大批量。判断：SGD 作为基础仍在用，作为唯一默认已被取代。

## 争议与局限
第一，SGD 的噪声是双刃剑：既可能帮模型离开尖锐区域，也让收敛在最优点附近抖动；学习率、batch size、衰减日程互相耦合，调错一个就发散或停滞。

第二，Bottou 的渐近分析建立在凸性、正则性与学习率衰减等条件上；深度网络非凸、有限时间、学习率往往分段常数，这些结论不能直接搬来做保证。第三，小批量并不是越大越好：Goodfellow 指出更大的 batch 只带来「次线性」的梯度精度回报，而内存随 batch 线性增长；同时小批量本身的噪声有正则化效果，batch size 为 1 时泛化误差常常最好，但训练步数多、总时间高。

第四，单样本 SGD 在 GPU 上几乎喂不饱算力，「纯在线」更多是数学理想；今天说的 SGD 多半指小批量 SGD。当时并非无人反对：传统优化界觉得随机梯度收敛慢、噪声大，Bottou 论文自己也用了「unlikely optimization algorithms」这样的说法，承认它反直觉；它的胜利是「按总时间算账」带来的，不是「每一步都更优」。
