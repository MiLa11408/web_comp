## 一句话

1999 年 8 月 31 日，NVIDIA 在 Palm Springs 发布 GeForce 256：这块为游戏塞进变换、光照和渲染的芯片，带着近 2,300 万晶体管、50 GFLOPs、每秒 1,500 万多边形和 4.8 亿像素，被叫作「世界上第一颗 GPU（图形处理器）」，也顺手给深度学习备好了并行算术。

## 时间·人物·机构

打游戏时，画面里每个三角形怎么转、每束光怎么落，都要有人算；在这之前，这活多半压在 CPU 身上。GPU（图形处理器）就是把这些重复的图形算术收进一块专用芯片：顶点变换、光照、上色各有各的电路。GeForce 256 是 NVIDIA 用「GPU」命名的第一块芯片。

NVIDIA 于 1999 年 1 月宣布首次公开发行 350 万股普通股；同年 5 月，它卖出了第一千万颗图形处理器，并发布 RIVA TNT2。8 月的 GeForce 256 由公司总裁兼 CEO 黄仁勋（Jen-Hsun Huang）在 Palm Springs 的活动上发布；11 月，NVIDIA 又推出面向工作站的 Quadro，并进入商用台式机市场。按 NVIDIA 自己的年表，这几件事都发生在同一年。

发布材料把 GeForce 256 的规格写得很直白：第一颗 256 位 3D 处理器、第一个集成几何变换引擎、第一个集成动态光照引擎、第一条四像素渲染管线。黄仁勋在新闻稿里的说法是，GPU 是「行业的一次重大突破」，会「从根本上改变 3D 媒介」。这不是一篇学术论文，而是一份产品宣言；「GPU」这个词，就是在这份宣言里被立起来的。

## 为什么是这个时候

1990 年代的 PC 游戏把越来越多的工作推给显卡：分辨率涨、帧率涨、三角形数量涨，CPU 既要跑游戏逻辑又要做几何变换和光照，忙不过来。NVIDIA 在新闻稿里回顾了自己的两步：1997 年的 RIVA 128 是「第一颗 128 位 3D 处理器」，1998 年的 RIVA TNT 是「第一颗双管线处理器」。到 1999 年，把这些分离的图形功能塞进一颗芯片，成了顺理成章的下一步。

另一个条件是 API。GeForce 256 支持 Microsoft DirectX 7.0 的立方体环境映射、投影纹理和顶点混合，也支持 OpenGL 的 ICD。游戏开发者有了统一的接口，硬件厂商就可以把更多功能做成固定电路。市场、接口和制程刚好凑齐，「集成」才有了意义。

这也是为什么 GPU 的第一份工作不是科学计算：它的客户是游戏玩家，评价标准是帧率和画面，而不是误差或收敛。芯片的架构被游戏需求塑造，后来才被别的领域重新发现。

## 怎么工作

GeForce 256 的图形管线可以按顺序拆成四步。第一步，CPU 把场景里的顶点坐标送进 GPU；第二步，集成几何变换引擎用 4×4 矩阵把顶点从模型空间搬到屏幕空间；第三步，集成动态光照引擎逐顶点计算颜色；第四步，三角形被光栅化成像素，四条像素管线并行着色，结果写进最高 128MB 的帧缓冲，再经 350MHz RAMDAC 输出，最高支持 2048×1536、75Hz。

打个比方，顶点变换像把一张设计图按同一把尺子缩放到另一张纸上：每个点都套一次 4×4 矩阵，算出它在屏幕上的位置。准确地说，集成几何变换引擎对每个顶点做矩阵乘向量，把模型空间坐标搬到屏幕空间，逐顶点计算彼此独立。

这些步骤里藏着关键：变换是矩阵乘向量，光照大量是向量点积，而每个顶点、每个像素的计算彼此独立。换句话说，同一套算术要被重复几百万次。GPU 的做法不是把每个计算做快，而是把大量简单的算术单元摆在一起，让它们同时做同样的指令、吃不同的数据。

用生活里的话说，这像一千个收银员同时处理一千张格式相同的小票：每个人只算自己那一张，动作却完全一样，所以可以一起开工。准确地说，GeForce 256 是固定功能管线，靠专用电路并行处理顶点和像素，并不是可编程的通用处理器；它具备的是「同一操作、不同数据」的并行形态，而不是任意程序的能力。

换个说法，固定功能管线像一条只做一道菜的流水线：切配、下锅、装盘的位置都焊死，火候和顺序不能改，但一秒能出几千份。准确地说，GeForce 256 把变换、光照、三角形设置和渲染做成专用电路，指令序列固定，开发者只能通过 API 调参数，不能给每个顶点写自己的程序。

NVIDIA 给这组数字的对比很夸张：近 2,300 万晶体管，比 Pentium III 复杂一倍以上；50 GFLOPs 的 3D 浮点算力，相当于一台满配的 256 处理器 Cray T3D；每秒 1,500 万多边形、4.8 亿像素。这些是厂商在发布时的标称值，不是独立评测，但足以说明它的设计取向：用海量并行换吞吐。

## 它改变了什么

第一，它把「GPU」变成了一个产品类别。此前显卡常被当作 3D 加速卡或图形加速器，职责偏向光栅化；GeForce 256 用「单芯片集成变换、光照、渲染」重新划了边界。名称是营销，但分工是真实的：CPU 管逻辑和通用计算，GPU 管大量重复的图形算术。

第二，它把图形管线从主板和 CPU 手里拿走。几何变换和光照原本可以由 CPU 做，集成之后，游戏厂商可以假定这些工作由显卡完成，进而把预算花在更复杂的场景上。NVIDIA 同年进入商用台式机市场、推出工作站 Quadro，也是这条产品线的延伸。

第三，它为后来的通用计算留下了硬件条件。大量并行浮点单元、宽内存接口、高吞吐的像素管线，这些为图形设计的特性，恰好也是矩阵运算需要的。之后 GeForce 3 引入可编程着色器，开发者开始能改写显卡上的程序；再往后，b16-c2 的 CUDA 把这扇门正式打开。1999 年的这颗芯片自己不会做深度学习，但它把「用几千个简单单元同时算」这件事变成了消费级硬件。

## 今天的地位

作为产品，GeForce 256 早已退役：固定功能的变换与光照电路、DirectX 7 时代的管线，都进了技术史。作为品类，它仍然在场：今天每一颗 GPU 都还叫 GPU，PCIe 插槽上的显卡仍然是 PC 里除 CPU 之外最值钱的运算部件。

但今天 GPU 的内核已经换了好几代。固定管线变成了可编程着色器，后来又加上了统一计算架构、矩阵单元和 AI 加速器；「变换、光照、渲染集成在一颗芯片」这个 1999 年的定义，放在今天已经不准了。判断是：GeForce 256 是 GPU 这个品类的命名起点和架构起点，但不是现代通用 GPU 的完成品；它证明了并行图形硬件的价值，通用性则要等 CUDA 来补。

## 争议与局限

「第一颗 GPU」是 NVIDIA 自己的定义。新闻稿把 GPU 界定为「一颗单芯片，集成变换、光照、三角形设置与渲染」；按这个标准，GeForce 256 是第一个。但在此之前，PC 上已经有 3D 加速芯片，只是分工和集成度不同。这不是一场由独立机构裁判的比赛，而是一次成功的品类命名；把它当成绝对的技术分界线，会漏掉更早的图形加速史。

它也不通用。GeForce 256 的变换和光照是焊死的电路，不能跑任意程序；没有通用寻址的大内存模型，没有今天意义上的浮点标准与纠错机制。想拿它做科学计算，必须先把它当图形设备来骗：把数据包装成纹理，把计算写成渲染。这个门槛，正是 CUDA 要拆掉的墙。

还有口径问题。50 GFLOPs、1,500 万多边形、4.8 亿像素都是发布时的标称值；「相当于 256 处理器 Cray T3D」是 NVIDIA 自己的类比，比较的是特定 3D 浮点负载，不是通用基准。读这类数字，要知道它们回答的是「图形吞吐够不够」，不是「能不能做科学计算」。

## 关系

本章是《算力的地基》的开篇，前置为空。它回答的是硬件问题：为什么一块为游戏设计的芯片，会长出适合矩阵运算的骨架。

后继 b16-c2「CUDA：把显卡变成通用加速器」接的是软件问题：同一批并行单元，如何让不会写图形管线的科学家也能调用。再往后，b16-c3 的 AlexNet 用两块 GTX 580 把这条链路跑通，证明游戏卡可以训练深度网络；b16-c4 的 TPU 则走向另一条分支，用专用电路换取推理效率。当前无跨书换乘。
