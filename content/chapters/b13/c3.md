## 一句话
2020 年 OpenAI 把模型堆到 1750 亿参数、96 层，训练后不做任何微调，只靠提示里的任务说明和几个例子，就能做翻译、问答和算术。它把「上下文学习」（看几个例子就会新任务）变成正式能力，也让语言模型第一次以 API 形式对外开放。

## 时间·人物·机构
2020 年 5 月 28 日，OpenAI 在 arXiv 提交《Language Models are Few-Shot Learners》（arXiv:2005.14165），第一作者 Tom B. Brown，合作者名单长到三十余人，包括 Benjamin Mann、Nick Ryder、Jared Kaplan、Alec Radford、Ilya Sutskever、Dario Amodei 等。模型叫 GPT-3，1750 亿参数，是当时最大的非稀疏语言模型，比此前任何非稀疏模型大 10 倍。训练在微软提供的高带宽 V100 集群上完成；6 月 11 日，OpenAI 开放 API 内测，文本进、文本出，底层跑的就是 GPT-3 系列权重。

## 为什么是这个时候
GPT-2 已经露出苗头：模型越大，零样本越像样。但 2019 年的主流仍是「预训练 + 微调」，每个任务都要几千到几万条标注，标注成本成了天花板。GPT-3 的赌注是：如果参数再大两个数量级、数据再杂一些，模型能不能直接从提示里的几个例子里「读出」任务，而不改一个权重？这时候算力、数据、架构三样都够用了：Transformer 解码器可以堆到 96 层，网页语料可以喂到更大的规模，微软的集群能撑住模型并行。于是「少样本」从一个评测设置变成了产品设计的中心。

## 怎么工作
GPT-3 仍是自回归语言模型：给定前文，预测下一个 token，一层层堆到 96 层，隐藏维 12288，上下文 2048 个 token，训练批量 3.2M，学习率 0.6×10⁻⁴。它没有任何任务专用的结构，输入就是一段文本：任务说明、几个「问题—答案」示例，然后是待答的问题。模型顺着这段文字往下写，把答案续出来。
用白话讲，这像开卷考试，你把例题和题目一起抄在答题纸上，它照着例题的格式往下填；准确地说，这叫上下文学习——不更新参数，只利用上下文里给出的示例来推断任务，前向一次就出结果。零样本是一道例题都不给，单样本给一个，少样本给十几个到上百个，都在同一个模型里完成。
代价体现在账单上：论文给出的训练算力是 3.14×10²³ FLOPs；按 2020 年 V100 云算力折算，约 355 GPU 年、单次训练 460 万美元——这是外部机构 Lambda 的估算，不是 OpenAI 公布的账单。用大白话，这是几百张卡跑一年、烧掉一笔小公司全年预算；准确地说，这是按理论 28 TFLOPS、三年预留云价折算出的量级，真实成本会因利用率和折扣而变。
API 则把这套能力包成服务：开发者不用自己训练，发一段提示，付钱拿补全。6 月的内测博客写明，API 的第一批用户包括 Algolia、Quizlet、Reddit 与明德学院等。

## 它改变了什么
第一，它把「提示工程」推到了台前：既然不改参数，怎么把任务写清楚、给几个例子，就成了新的手艺。第二，它把大模型变成了可租用的基础设施：API 让没有算力的公司也能调用 1750 亿参数，模型能力第一次以「每千 token 多少钱」的方式进入产品预算。第三，它点燃了规模竞赛：GPT-3 之后，参数与数据规模成了公开的军备表，也逼着大家重新讨论「涌现能力」到底是不是真的。第四，它改变了评测话语：少样本成为论文的标准栏目，后来的模型都要在同一套零样本/少样本设置下比较。第五，它让「通用模型」这个词有了具体的产品形态：一个接口，而不是一堆任务专用模型。

## 今天的地位
GPT-3 的原始权重早已不是最强的，1750 亿在 2026 年也算不上大；但它定下的交互范式仍在用：系统提示、少样本示例、把任务写成自然语言。API 这条线也从 2020 年的内测长成了今天的产品体系。它在历史上的位置是「转折点」：把语言模型从「预训练 + 微调的研究对象」变成了「按提示工作的通用服务」。同时，它也是「规模不是万能」的教材——论文自己列出了一批少样本仍然失败的任务。今天回看，它最持久的遗产不是某个权重文件，而是「提示即接口」这个默认设定：模型不必为每个任务重训，用户只要把任务说清楚。

## 争议与局限
第一，能力边界：论文承认，在一些数据集上 GPT-3 的少样本学习仍然吃力，尤其是需要强推理或精确计算的任务；三位数算术能做，不代表会算账。第二，数据污染：训练语料来自大规模网页，评测集可能以某种形式出现在训练数据里，论文专门讨论了这一方法论问题，但无法彻底排除。第三，成本与门槛：单次训练数百万美元、355 GPU 年的量级，把学术实验室挡在门外，也让「规模竞赛」的批评有了具体数字。第四，偏见与滥用：和 GPT-2 一样，网页语料会把性别、种族、宗教偏见带进输出；API 博客把滥用防护写成产品的一部分，但这也意味着审核权集中在供应商手里。第五，科学解释不足：为什么参数到一定规模就会「会做新任务」，论文给的是曲线和评测，不是机制解释；「涌现」后来一直是争论点。第六，环境与能源账单不在论文里，却是真实的外部成本。
