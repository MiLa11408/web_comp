L4 的暗门

录制视频的亮点镜头
  1. L4 蜡封桌上多一张盖着红 X 的备忘「第十柜未编目 / 右墙帷幕后 / 十道脊 = 钥匙」
  2. 右墙帷幕没有拉直，点它滑开 → 露出不在平面图上的铁门
  3. 门后是十本「假如之书」（1956 达特茅斯 → 2024 开源）选一条科技树：符号树 / 神经树 / 具身树　·　点「走假如」→ 生成 12 段约 1400 字的科幻推测，换树内容不同
  4. 书架尽头还有第十一本「未写之书」只接受「如果没有 X 会怎么样」，调 DeepSeek V3.2 生成只与问题相关的小故事，不合格式直接拒绝

安全SECURITY12 / 16

安全性

Defense in depth
认证
密码 scrypt 慢哈希 + 随机盐；会话 token 签名鉴权
注入
全部 SQL 走参数化查询；注册/登录/IP 级限流
未写之书 API
输入格式白名单校验 + 8 次/10 分钟限流 + 最大 token 限制
密钥
