# PLAN_TIERS.md · 资料分级 × 残页 × 电梯（Boss 2026-11-07 提案的设计稿）

> 一句话：**电梯往上，知识越前沿，书页越残破，真相越神秘**；散落的残页拼成一本不存在的书《另一条时间线》——每一页都是基于真实事实的「假如」，标明推测，但让人看见历史本来可以不是这样。

---

## 1. 核心规则（楼层 = 知识梯度）

| 楼层 | 主题 | 知识等级 | 残破度 | 神秘度 | 视觉/阅读呈现 |
|---|---|---|---|---|---|
| L1 历史典藏 | 起源、人物、会议、论文原件 | Tier I 基础 | 0 完好 | 0 | 暖光、旧纸、正文完整 |
| L2 技术工坊 | 机制、实现、数字、工程细节 | Tier II 进阶 | 1 轻残 | 1 | 冷蓝光、蓝图、边缘偶有烧焦痕迹 |
| L3 产业观察 | 产业、算力、成本、政策 | Tier III 高端 | 2 中残 | 2 | 琥珀暗光、报告纸、账本缺页 |
| L4 未编目地库 | 前沿、未定论、失败与「假如」 | Tier IV 机密 | 3 高残 | 3 | 近黑、冷紫、封蜡、残页几乎空白 |

规则：
1. **等级越高，内容越前沿**（历史 → 技术 → 产业 → 未编目/前沿）。
2. **等级越高，残破越重**：L1 完整；L2 少量缺句；L3 成段缺失；L4 只剩只言片语 + 封蜡。
3. **等级越高，神秘度越高**：L4 的章节会出现「未编目」戳、「自相矛盾」批注与推测标注。
4. **事实底线不动**：残破的是「可读性」，不是事实。数字、来源、年份一律按已核验内容；「假如」线全部标「推测」。

---

## 2. 资料分级（内容侧）

- 章节等级 = 所属楼层等级（不新增字段，`book.floor → floors.json.tier`）。
- 各等级对写作与呈现的要求：

| 等级 | 作者写什么 | 读者看到什么 |
|---|---|---|
| I 基础 | 史实、人物、原件 | 完整 9 段 + 页边注 |
| II 进阶 | 机制、工程数字、实现细节 | 完整 9 段 + 「工坊批注」标记 |
| III 高端 | 数据、成本、产业影响 | 9 段 + 「账本缺页」空白条 |
| IV 机密 | 前沿、争议、未定论 | 9 段 + 「未编目」戳 + 封蜡 + 残页槽 |

---

## 3. 残页机制（《另一条时间线》）

- 8 张残页 `R-01 … R-08`，每张藏在指定章节里（`fragments.json`），**不替代任何正文内容**。
- 残页内容全部是「假如」：**基于真实锚点**（会议、论文、数字）推演另一种走向，每页顶部标「推测」。
- 残破程度（torn 0–3）：
  - torn 0：完整可读（L1）
  - torn 1：缺 15%（L2）
  - torn 2：缺 30%（L3）
  - torn 3：缺 45%，只剩开头几句 + 封蜡（L4）
- 收集与修复（阶段 5 实现交互）：
  1. 读到藏有残页的章节 → 页边出现「残页槽」；
  2. 收编残页 → 加入《另一条时间线》收藏；
  3. 8 张齐 → 拼成完整故事线，L4 解封；
  4. 缺页章节会显示「缺页 X 字」，不假装完整。
- 故事线顺序（与历史主线的对应）：

| 残页 | 假如 | 藏在（章节） | 楼层 |
|---|---|---|---|
| R-01 | 达特茅斯会没开成 | b1-c3 | L1 |
| R-02 | 符号主义赢了、寒冬没来 | b2-c6 | L2 |
| R-03 | 1986 反向传播没发表 | b3-c4 | L2 |
| R-04 | 没有 ImageNet | b8-c2 | L2 |
| R-05 | AlexNet 没赢 | b10-c7 | L3 |
| R-06 | AlphaGo 输了 | b7-c5 | L3 |
| R-07 | 2022 没有 ChatGPT | b5-c5 | L4 |
| R-08 | 开源大模型不存在 | b12-c3 | L4 |

> 注：主书名《另一条时间线》，8 页按 R-01→R-08 顺序读才完整；单看任何一张都只是「半句话」。

## 4. 与电梯结合

- 电梯不再只是导航，而是**知识梯度**：每层显示 `等级 + 残破度 + 馆员`。
- 到站欢迎语按馆员个性（已在 `content/floors.json`）。
- 场景氛围随楼层变化：楼越高，雾越浓、光越暗、尘埃越少、色调越冷——「越往上越神秘」。
- 电梯面板按钮模板：

```
历史典藏        等级 I · 完好      旧纸馆员
技术工坊        等级 II · 轻残     蓝图馆员
产业观察        等级 III · 中残    账簿馆员
未编目地库      等级 IV · 高残     蜡封馆员
```

## 5. 数据契约（改数据不改代码）

### floors.json（新增字段）
```json
{ "id": "L2", "name": "技术工坊", "librarian": "蓝图馆员", "welcome": "……",
  "color": "#3f6b8a", "tier": 2, "tierName": "进阶", "decay": 1, "mystery": 1,
  "tagline": "图纸的边缘有烧焦的痕迹" }
```

### fragments.json（新）
```json
{
  "ifline": { "title": "另一条时间线", "en": "The Other Timeline", "desc": "……", "total": 8 },
  "fragments": [
    { "id": "R-01", "order": 1, "floor": "L1", "chapter": "b1-c3",
      "title": "假如达特茅斯没开成", "torn": 0, "text": "……（标推测）" }
  ]
}
```

### 接口
- `GET /api/floors`（含分级字段）
- `GET /api/fragments`（残页数据）
- 阅读页：接待卡显示 `楼层 · 等级 · 残破度`；本章藏有残页时显示「残页 R-0x · 未收编」；右栏显示总进度 `0/8`。

## 7. 风险与红线

1. 「假如」线必须逐条标注**推测**，不得写成史实；锚点必须引用真实章节内容。
2. 残页不承载唯一来源：任何章节的关键事实都不能只存在于残页里。
3. 残破度是**叙事表现**，不能删改已核验的数字与结论。
4. 不做付费解锁、不做排名竞争。
