## 技术方案：无构建、可审计、轻依赖

- **前端**：原生 HTML/JS + three.js（本地 vendor）+ Rapier 物理 + WebAudio
- **后端**：Fastify 5 + Node 内置 `node:sqlite`（零数据库服务）
- **内容**：Markdown + YAML frontmatter + JSON（内容与代码分离）
- **部署**：systemd + nginx 子路径 `/ai/`，`npm ci --omit=dev` 即上线
- **运维**：arXiv 每日 04:17 自动入库、每日 03:40 自动备份（保留 14 天）

<!-- 备注：评委问到「技术选型为什么」——答：无构建步骤 = 任何一台 Node ≥ 22.5 的机器三条命令跑起来 -->

## 安全性

- 密码：**scrypt 慢哈希** + 随机盐；会话 token 签名鉴权
- 全部 SQL 走参数化查询；注册/登录/IP 级**限流**
- 未写之书 API：输入格式白名单校验 + 8 次/10 分钟限流 + 最大 token 限制
- 密钥放服务器 `.env`（权限 600），**不进仓库、不进压缩包**，只提供 `.env.example`
- 访客**只读**全部内容；盖章/批注/进度才需借书证
- 部署：自签 https + http 双入口，CSP 收紧与最小权限
