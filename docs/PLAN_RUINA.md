## 1. 这是一款什么游戏（事实对齐）

| 项 | 内容 |
|---|---|
| 开发/发行 | Project Moon（韩国独立工作室） |
| 平台与发售 | PC（Steam）2021-08-10 正式发售；2024-04-25 登陆 Switch / PS4 |
| 官方标语 | 「正于此地，愿您找到想要的书。」 |
| 类型 | 官方归类「图书馆战斗模拟」（Library Battle Simulation） |
| 前作 | 《脑叶公司》（Lobotomy Corporation，2016 年底抢先体验、2018-04-09 正式版） |
| 核心循环 | 扮演馆长接待「宾客」→ 司书在图书馆舞台上迎战 → 落败宾客化作**书** → 图书馆随接待扩建 → 拆解书籍获得**书页** → 终点是「唯一一本完美的书」 |
| 世界观 | 「都市」边缘的一座图书馆；楼层由不同司书驻守，各自风格与故事 |

**我们借的是这套「知识=书 / 来访=接待 / 获得=书页」的空间化仪式，不是它的美术与叙事。**

## 2. 内容风格（已采纳）

### 2.1 页边注 → 馆员批注（署名制）✅
每层一位原创馆员，页边注由当班馆员署名，前端按楼层自动署名、作者不用写名字：

| 楼层 | 馆员 | 批注个性 |
|---|---|---|
| L1 历史典藏 | 旧纸馆员 | 考据癖、爱翻旧账、对「当年预算」格外敏感 |
| L2 技术工坊 | 蓝图馆员 | 工程师口吻，爱算账、爱挑实现毛病 |
| L3 产业观察 | 账簿馆员 | 行业分析师，冷幽默、张口就是数字 |
| L4 未编目地库 | 蜡封馆员 | 神秘、话少、偶尔一语中的 |

### 2.2 接待卡开场 ✅
每章开头一张「接待记录」小卡（已实现，字段全部由已有数据生成，不新增内容）：

```
接待记录 No. A-03
宾客：达特茅斯会议（1956）
来访目的：一句话摘要
当值馆员：旧纸馆员
接待结果：已收编 / 已收编 · 缺一页（有失窃页时）
```

### 2.4 楼层导语 + 电梯欢迎语 ✅（阶段 2 随电梯实现）
电梯到站时播放当值馆员的一句欢迎语，文案按 §2.1 的个性写，不做统一模板。

### 2.5 语气基调 ✅
各馆员语气要**不一样**：旧纸 = 考据式吐槽；蓝图 = 工程式吐槽；账簿 = 数字式吐槽；蜡封 = 冷面短语。但共同红线不变：数字不改、来源不删、争议不糊、不调侃真实人物的苦难。

### 2.3 来源 = 书页卡 ✘
不采用。档案段保持现状（编号列表 + URL + 核验说明），不改造成卡牌。

## 3. 趣味性（已采纳 / 改造采纳）

### 3.1 借阅证 → 司书证 ✅（阶段 2 注册页）
注册页写成「入职登记」：用户名 = 胸牌名；读完首章盖「入职章」。

### 3.2 / 3.3 收编章 + 书页收集 ◐
- 读完一章盖「收编」章，不再叫「已读」；一章来源不集齐也照常盖章（**不把重要内容做成可丢失的收集品**）。
- **丢失书页改为原创平行故事线**：不拿任何正文/来源当丢失物。另外写 **8 页「假如」故事**，可串联成一本完整的《另一条时间线》：

| 页 | 假如 | 藏在哪（阶段 5 定） |
|---|---|---|
| 1 | 假如 1956 年达特茅斯会没开成 | 序卷某章夹层 |
| 2 | 假如符号主义赢了、连接主义没复兴 | 符号的世纪 |
| 3 | 假如 1986 年反向传播没被发表 | 神经的复活 |
| 4 | 假如没有 ImageNet | 感知与语言 |
| 5 | 假如 2012 年 AlexNet 没赢 | 神经的复活／技术工坊夹层 |
| 6 | 假如 2016 年 AlphaGo 输了 | 行动的智能 |
| 7 | 假如 2022 年没有 ChatGPT | 注意力纪元 |
| 8 | 假如今天的开源模型不存在 | 未编目 |

读者找齐 8 页 → 在 L4 未编目地库拼成《另一条时间线》，解锁蜡封馆员的结局批注。每页都标「推测」，与 TOC 已有的「历史分岔」合并实现。

### 3.4 章节总结卡 ✅（阶段 3）
读完一章自动生成卡片：标题 / 年代 / 三位关键人物 / 一句金句 / 一个争议点 / 三条来源，支持导出图片。

### 3.5 躁动书页 ✅（阶段 5，按 Boss 意见「稍微延展」）

失败博物馆 20 件失败做成「未收编的躁动书页」，藏在章节、失窃页、电梯夹层，找到触发特别批注。与失窃页机制合并，不新增系统。

**稍微延展（不加系统，只加叙事层）**：
- 三种状态：**安静**（藏好未被发现）→ **躁动**（被读到，书页在页边注里插话）→ **归位**（被拖回它所属的章节后盖「安抚章」）。
- 每张躁动书页带一个「收容编号」和一句它不服气的话，例如「我不是失败，我是提前到场」「你们把我写进失败博物馆，版权费呢」。
- 归位判定复用失窃页：拖到正确章节即解锁全文，错章只回一句讽刺。
- 全部复用现有的藏匿点、印章与页边注系统，不新增玩法模块。

### 3.6 楼层平面图 ✅（阶段 2）
每层一张手绘感平面图（书架/桌/装置位置），与 3D 场景共用数据；电梯选层先见平面图。

## 4. 功能

### 4.1 阅读三栏 ✅（本轮已实现）
- 左栏：全馆检索 + 「本章命中 N 处」定位列表，可收起（⟨ 按钮）
- 中栏：正文（四材质纸色）+ 接待卡
- 右栏：页边注小字卡片，可点击锚点跳到对应段落并高亮
- 移动端：右栏折叠到正文下方，左栏收成图标

### 4.2 检索结果卡牌化 ◐ 暂缓
等主线（3D 阅览室 + 96 章）完成后再评估视觉升级。

### 4.3 关系网「红线」 ✅（阶段 4）
书与书之间的细红线沿用；只作叙事氛围，不新增系统。

## 5. 明确不借鉴（维持）

| 不做 | 原因 |
|---|---|
| 复制 Project Moon 的美术、音乐、角色、台词、UI 图案 | 版权与参赛合规 |
| 使用原作的司书名、楼层名 | 避免 IP 混淆 |
| 卡牌战斗 / 数值 / 抽卡玩法 | 与知识馆定位不符 |
| 黑暗猎奇、死亡收编等暗黑叙事 | 科普定位 |
| 付费或排名化的收集品 | 非商业、非竞技 |

## 7. 说明：3.5 的延展范围（Boss 澄清）

Boss 原话「3.5 开一段可以在学校还有什么可以做成相似的」中的「学校」为输入误字，实际意思是**「稍微延展」**。因此不做校园场景，改为 §3.5 内的一小段延展（三种状态 + 收容编号 + 归位判定）。此处保留原「校园延展」设想仅作存档，**不进入开发范围**：

- （存档，不做）校园版躁动书页 / 班级接待日 / 社团图书角 / 毕业「假如」档案。
